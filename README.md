# NEVALUZ — Catálogo digital editorial

Catálogo web de lámparas artesanales hechas a partir de frascos de vidrio recuperado. La interfaz está diseñada como una experiencia editorial de escritorio y móvil con colección limitada, fichas interactivas y pedidos directos por WhatsApp.

## Producto
- **Cabaña** — S/ 8
- **Reno** — S/ 12
- **Dúo Cabaña + Reno** — S/ 20
- Ediciones numeradas y personalizables.

## Activos
Las imágenes de producto son recortes de fotogramas reales del material entregado para conservar la identidad visual del producto. El video original no se muestra, carga ni incrusta en el sitio.

## Desarrollo local
```bash
python3 -m http.server 4173
```
Abrir `http://localhost:4173`.
