# NEVALUZ — brand spec

## Esencia
Lámparas artesanales para regalar momentos cálidos, hechas a partir de frascos de vidrio recuperado. Personalidad: **cálida, consciente, memorable**.

## Dirección visual
Editorial de lujo cálido: fondos carbón, tipografía serif expresiva, acentos de latón y fotografía de producto con luz ámbar. La composición mezcla asimetría, aire y líneas orbitales para que el producto sea el protagonista.

## Sistema
- **Colores:** carbón `#0e0d0b`, carbón suave `#171410`, papel marfil `#eee7d8`, latón `#c8a45b`, oro cálido `#e8c87c`, texto secundario `#a79c88`.
- **Tipografía:** Cormorant Garamond para titulares y precios; DM Sans para navegación, etiquetas y texto funcional.
- **Motion:** entradas suaves en `cubic-bezier(.2,.75,.2,1)`, hover de imagen con zoom sutil, flotación lenta de la imagen hero, modal para detalle.
- **Layout:** editorial, con grandes márgenes y grilla de productos que rompe la simetría con una tercera pieza panorámica.

## Voz
Frases cortas, sensoriales y honestas. Evitar claims no demostrables. Ejemplos: “La luz también puede contar una historia.” / “Regala algo que se queda encendido.”
